# mind

Движок «сознание + подсознание» поверх двух корпусов: cmake-документы (`data/`)
и диалоги DailyDialog (`data2/ijcnlp_dailydialog/`).

## Запуск

```bash
cargo run --release              # всё: фаза 1 -> 2 -> 3 -> чат
cargo run --release -- --no-chat # без интерактивного чата
```

Опции:

| опция | смысл |
|---|---|
| `--steps N`   | шагов live-вывода фазы 1 (по умолчанию 600) |
| `--limit N`   | сколько диалогов взять из train (0 = весь сплит) |
| `--delay N`   | пауза между шагами live-вывода, мс (20) |
| `--max-reply N` | максимум токенов в ответе чата (24) |
| `--no-chat`   | не входить в чат |

## Фазы

1. **docs** — тот же live-поток, что и раньше; блок `[...]` красится от зелёного
   к красному по качеству текущего шага (`q=`), рядом `t1/t3` по следующему токену.
2. **dialogues** — обучение на DailyDialog: отдельный классификатор актов
   (inform/question/directive/commissive) и генератор ответа.
3. **eval** — те же метрики на официальном test-сплите.
4. **chat** — пишете строку, Enter, модель отвечает. Команды: `/quit`,
   `/help`, `/stats`, `/top`, `/act <1-4>`.

## Разделение признаков

Признаки docs-корпуса остались байт-в-байт прежними (`prev:`, `pair:`, `prev2:`).
Диалоговые изолированы префиксами, чтобы не портить обученную модель:
`a:*` — акты, `bag:`/`mode:reply`/`act:` — генерация ответа.
